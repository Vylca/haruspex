# haruspex_hunspell

[Hunspell](https://github.com/hunspell/hunspell) 1.7.5, the spell checker of
LibreOffice and Firefox, built as a shared library with the app and called
through `dart:ffi`.

`src/hunspell/` holds the unmodified library sources of the 1.7.5 release
(MPL 1.1 / GPL 2 / LGPL 2.1, see the COPYING files there).
